## Locale Architecture and Routing

- `/sr/` and `/en/` are statically generated by App Router. Serbian is the default.
- `/` returns HTTP 307 to `/sr/`, including when the request prefers English. No browser-language redirect, locale cookie, or localStorage is used.
- Trailing slashes remain consistent with Phase 1. Unsupported locales and unfinished local routes return 404.
- The native Next.js proxy also rejects uppercase locales before static-cache lookup. A production-server regression test caught `/SR/` incorrectly serving `/sr/` on the case-insensitive development filesystem; this is now covered and fixed.
- `lib/routes.ts` maps semantic route keys to future translated slugs. The switcher preserves known equivalent pages, including stable future portfolio detail slugs. Unknown paths have no switch target.
- Active language has `aria-current`, bold text, and an underline. SR/EN are semantic links with language and accessible labels, available on desktop and mobile, including without JavaScript.
- Future pages should load the shared dictionaries and enable their route-registry entry only when both locale versions exist. No placeholder core pages or case studies were added.

## Responsive and Accessibility Decisions

- Explicit mobile/tablet/desktop breakpoints reuse Phase 1 tokens, gutters, and container limits. Hero actions fit together at the requested phone widths, with a deliberately smaller mobile montage.
- Portfolio becomes one column on mobile and alternates paired/full-width entries from tablet upward. Services and FAQ use stacked mobile layouts and editorial desktop columns.
- Semantic sections, articles, ordered service list, one H1, and logical H2/H3 hierarchy.
- Keyboard skip link, visible focus, localized accessible labels, and retained native mobile navigation behavior.
- FAQ uses semantic buttons, `aria-expanded`, `aria-controls`, and labelled panels. All answers render visibly without JavaScript; enhancement opens the first answer and enables toggling. No duplicate fallback markup or height animation.
- Existing reduced-motion rules remain in force. Decorative Lucide icons are hidden from assistive technology.
- Server Components remain the default. Only MobileNavigation, LanguageSwitcher, and FAQAccordion have explicit client boundaries. No dependencies were added.

## SEO Decisions

Both locale pages have translated titles/descriptions, distinct production canonicals, `sr`/`en` hreflang equivalents, Serbian `x-default`, localized Open Graph data, and Twitter sharing metadata. HTML language is `sr` or `en` as requested.

Both pages remain `noindex, nofollow`, even in production builds. No speculative business redirects, sitemap, robots route, or structured data were introduced. These remain intentional launch work; enabling indexing must not expose development or preview deployments.
